# Corrections to the EPAM II transcription (epamfixed.card)

`epamfixed.card` is the earlier transcription of the EPAM II listing in the
appendix of E. A. Feigenbaum, *An Information Processing Theory of Verbal
Learning*, RAND P-1817 (9 Oct 1959), pp. 133ff (in
`~/Desktop/AIHistory/Documents/P-1817_Feigenbaum_EPAM_Oct59_OCRed.pdf`). It is
corrected here only where a card was checked against the page image and found
wrong. Changes made only to run it are in `make_run.py`, not here.

| Card ID | Printed page | Was | Listing | Note |
|---|---|---|---|---|
| CAPL26 | 134 | `21 Z0` (plus a remark card `+0`) | `21 Z` | The alphabet's Z. The remark card is removed. |
| Q0110, Q0111 | 149 | `J5`, `J5` | `J3`, `J3` | Q1, the code for A, the only letter code in the listing. |
| Q0115, Q0116 | 149 | `J4`, `J3` | `J3`, `J4` | Q1 now reads 10001100010111, as in the listing and the text (p. 71). |

Checked and found correct: A0000-A0008, CAPL01-CAPL25, DIFF 1-9, D00 01-37
(pp. 134-135), P0001-P0201 (p. 149, including P0's two definitions).
