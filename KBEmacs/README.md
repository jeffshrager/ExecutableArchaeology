# KBEmacs

**This project lives in its own repository: <https://github.com/jeffshrager/kbemacs>**

KBEmacs, the Knowledge-Based Editor of MIT's Programmer's Apprentice
(Richard C. Waters and colleagues, MIT AI Lab), has been transcribed
from the January 1985 listings and runs again under SBCL. The listings
were preserved by Kent M. Pitman, a member of the KBEmacs team.

Start with the repository's README and its *Hacker's Guide to KBEmacs*.
