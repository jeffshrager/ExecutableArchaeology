### 3. CogLean: EPAM's cognitive propositions in Lean 4 (`EPAM/LEAN/`, `coglean.md`)

- Jeff's request: express EPAM's assertions Lean-style, so they can be combined to prove, qualitatively,
  what EPAM is meant to show. He clarified that they should be **cognitive** assertions, like EPAM's
  propositions, not the code.
- **Lean installed** (Jeff chose machine-checked): elan in `~/.elan`, Lean 4.35.0, core only (no Mathlib).
  `lake build` takes about 5 s. The build dir `EPAM/LEAN/.lake/` is excluded through `.git/info/exclude`,
  because Jeff's global gitignore ignores `.gitignore` files.
- **Model:**
  - `Item := List Bool`;
  - `Net` = leaf (image or null) | test (feature, two branches);
  - noticing order = a list of features;
  - `Cue := Feature → Option Bool`;
  - selection of a cue is a relation, with either branch possible where the cue is silent (§3.5.1.2,
    "set H5 randomly").
- **20 theorems, all proved; no `sorry`; `#print axioms` shows only propext, Quot.sound and
  Classical.choice:**
  - `Selection.lean` (D2): `select_depends_only_on_noticed_features`, `discrimination_needs_a_difference`.
  - `Discrimination.lean` (F1, F1b): `learn_recognizes`, `learn_preserves`, `learnAll_recognizes` (one F1
    cycle per item), `learned_test_is_first_noticed_difference`, `scanCost_ge_of_agree`, and lemmas.
  - `Association.lean` (F2, R, D8): `cue_from_path_selects`, `oscillation` (the same cue selects y before
    the net grows, then can select w or y), `restoration`, `retroactive_inhibition`.
  - `Macro.lean` (M0, M1, M3): `trials_at_least_pairs`, `serial_position_effect` (further from the nearer
    anchor ⇒ more errors), `first_position_fewest_errors`, `errors_rise_toward_middle`,
    `errors_fall_toward_end` (bowed curve).
- The phenomena mapped: stimulus generalization (Fig. 4.1, trial 4, PEM/ROM), intralist similarity,
  oscillation, D8 recovery, retroactive inhibition, learning to criterion, and the serial position effect
  (Feigenbaum & Simon 1962).
- **Simplifications, listed in the README:**
  - one test per confusion (P2 = 1), and no F1a;
  - the cue is the minimal path cue;
  - the simplest anchor-point schedule;
  - possibility rather than probability;
  - not yet stated: response generalization, error types, serial anticipation vs paired associates.
- **`coglean.md`** (repo root): the general project. For each classic model, state its cognitive
  propositions as definitions, the claimed phenomena as qualitative theorems, and prove them, checked.
  It describes how this relates to executable archaeology (program and theory check each other) and lists
  candidates (LT, Heuristic Compiler, Simon-Yngve's depth hypothesis). It is linked from the README.
